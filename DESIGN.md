# Design System

## Direction

Рабочая сметная ведомость на столе архитектора: светлая, собранная, с графитовым текстом и редкими тёплыми акцентами. Цветовая стратегия — restrained.

## Color

- Background: `oklch(1 0 0)`
- Surface: `oklch(0.965 0.004 70)`
- Ink: `oklch(0.19 0.012 55)`
- Muted: `oklch(0.47 0.012 55)`
- Primary: `oklch(0.61 0.16 68)`
- Accent: `oklch(0.25 0.07 16)`
- Success: `oklch(0.48 0.105 151)`
- Warning: `oklch(0.58 0.15 55)`
- Error: `oklch(0.48 0.18 25)`

## Typography

Один интерфейсный sans-serif: системный стек. Заголовки 600, основной текст 400–500, табличные цифры с `font-variant-numeric: tabular-nums`.

## Layout and Components

Максимальная ширина 1180 px. На desktop ввод и результат образуют две колонки; на mobile — последовательный поток. Радиус панелей 14 px, элементов управления 10 px. Акцент используется только для основного действия и ключевой суммы.

## Motion

150–220 ms только для обратной связи, раскрытия уточнений и появления результата. При `prefers-reduced-motion` переходы отключаются.
